# Daybreak Study Planner

[Open the live Planner](https://daybreak-study-planner.vercel.app/planner) · [Study Support](https://daybreak-study-planner.vercel.app/) · [Download the launcher](https://github.com/Poohkao2026-beep/Daybreak-study-planner/releases/tag/preview-0.2.0-1)

Daybreak helps students decide what to study next, protect time for focused work, and see how much room is left before a deadline. The English and Thai web preview is available now. The official web launch is targeted for **March 2027**.

Read the [current features, access requirements, technical stack and monthly roadmap](packages/planner-launcher/README.md). The public repository contains the preview launcher and the earlier Foundation source. For local development of that earlier edition, see the [Foundation guide](FOUNDATION.md).
