# Daybreak guest preview: a short feedback run

Use this checklist if you are trying the [hosted Planner](https://daybreak-study-planner.vercel.app/planner) for the first time or checking a reported issue. The hosted preview and the earlier Foundation checkout are different versions. This checklist is for the hosted preview only.

## Before you start

- Use a fresh browser profile, or a browser you don't use for your real planner.
- Stay in guest mode. Use fictional data. Don't sign in, turn on optional AI features, or upload a real schedule.
- Record your browser, device or viewport, language, and date tested.

## Try one study task

1. Open the Planner in English. Create a fictional course called “Sample Biology.”
2. Add “Review cell diagrams” and set a study date earlier than the due date.
3. Open Today on the study date, or choose that date in the planner. Check whether the plan makes the study date and due date easy to tell apart.
4. Start a short focus session from the planner and check that you can reach the timer controls. Stop the timer when finished.
5. Reload the page in the same browser profile. Check whether the sample course, task, and two dates persist.
6. Switch to Thai (ไทย), or start a new guest session in Thai. Repeat the task and timer steps. Check for clipped controls, missing translations, or text that is hard to understand.

If you can't complete a step, record where you got stuck instead of guessing what should happen. On a phone, check whether you can reach the controls without horizontal scrolling.

## Share useful feedback

Use the [Daybreak bug report form](https://github.com/Poohkao2026-beep/Daybreak-study-planner/issues/new?template=daybreak-bug.yml). Give the shortest sequence that shows the problem, what you expected, and what happened. Include only redacted screenshots with sample tasks. Don't post account details, student information, or planner backups.

For a local Foundation issue, follow the [Foundation guide](../FOUNDATION.md) and select “Local Foundation checkout” in the issue form.
