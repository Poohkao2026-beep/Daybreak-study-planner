# Daybreak study sprint

One short session for when you know what you should study, but not where to start. Use it in [Daybreak Planner](https://daybreak-study-planner.vercel.app/planner) or on paper. No AI or sign-in is needed for this workflow.

## Plan → Focus → Recall → Review

1. **Plan (2 min).** Turn one topic into something you can do or explain. In Daybreak, add it as a task and pick a study date. Keep the due date for the real deadline.
2. **Focus (15–25 min).** Start a short focus session. Work only on that task. If it feels too large, finish one useful piece instead.
3. **Recall (3 min).** Close your notes. Write or say what you remember, then reopen the source and correct one gap. This is a check, not a grade.
4. **Review (1 min).** Add a follow-up task for the part you missed. Tomorrow is an easy starting point if it fits; move it earlier if the deadline is closer.

### Worked example: one biology topic

| Step | Example |
| --- | --- |
| Plan | Study Tuesday; quiz Friday. Task: “Draw a cell membrane and explain why some molecules cross it.” |
| Focus | Draw the diagram and work through one example: oxygen versus a charged ion. |
| Recall | Close the book, redraw the membrane, and explain why the ion usually needs a transport protein. Check the answer and circle the mistake. |
| Review | Add a task for Wednesday: “Explain membrane transport without looking; test one new example.” |

### Copy this for your next session

```text
Course / topic:
One thing I want to be able to do or explain:
Study date:
Actual deadline (if any):
Focus time:

With my notes closed, I remembered:
One thing I missed or got wrong:
Next review date:
One question I’ll try to answer from memory next time:
```

**If you only have five minutes:** Pick one question, answer it with your notes closed, and check one mistake. Schedule the next attempt before you stop.
